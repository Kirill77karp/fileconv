# Стратегия тестирования

## Виды тестов

- **Unit (10+):** конвертеры, чистые функции. Без БД и HTTP.
- **Integration (3+):** API + БД + мок Celery.
- **E2E (1+):** полный сценарий пользователя.

## Покрытие

Целевое — ≥ 70%. Отчёт через pytest-cov, публикация на Codecov.

## Запуск локально

```bash
pytest
pytest --cov=src --cov-report=html
