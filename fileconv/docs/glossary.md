# Глоссарий

| Термин | Определение |
|--------|-------------|
| Конвертация | Процесс преобразования файла из одного формата в другой |
| Задача (task) | Асинхронная операция конвертации с уникальным ID |
| Исходный формат | MIME-тип или расширение загруженного файла |
| Целевой формат | Формат, в который конвертируется файл |
| Хранилище | Место хранения исходников и результатов (S3 / локально) |
| Воркер | Celery-процесс, выполняющий конвертацию асинхронно |
| JWT | JSON Web Token — токен аутентификации |
| bcrypt | Алгоритм хэширования паролей |
| Rate limit | Ограничение числа запросов в минуту |
| TTL | Time To Live — время жизни файла |
| Multipart | Формат HTTP-запроса для загрузки файлов |
| Pillow | Python-библиотека для работы с изображениями |
| pandas | Python-библиотека для работы с таблицами |
| Celery | Очередь задач для Python |
| Redis | In-memory хранилище, используется как брокер |
| Alembic | Инструмент миграций для SQLAlchemy |
| OpenAPI | Спецификация REST API |
| Pydantic | Библиотека валидации данных в Python |
