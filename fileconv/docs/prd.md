# Product Requirements Document — FileConv

## 1. Overview

FileConv — REST API для конвертации файлов между форматами.
Целевая аудитория: разработчики, аналитики, офисные сотрудники.
Проблема: существующие онлайн-конвертеры требуют ручного клика,
не имеют API и не подходят для автоматизации.

## 2. Goals and Non-Goals

**Goals:**
- API для конвертации png/jpg/webp, docx→pdf, csv↔xlsx.
- Асинхронная обработка тяжёлых задач.
- История конвертаций с возможностью скачивания.

**Non-Goals:**
- Видео и аудио.
- Оффлайн-режим.
- Более 10 форматов на MVP.

## 3. User Personas

### Аналитик Анна
- **Цель:** быстро превратить csv из выгрузки в xlsx для отчёта.
- **Боль:** Excel ломает кодировку при ручном импорте.
- **Сценарий:** загружает csv → получает xlsx → скачивает.

### Разработчик Дмитрий
- **Цель:** автоматизировать конвертацию png→webp в CI.
- **Боль:** CLI-утилиты требуют установки и настройки.
- **Сценарий:** вызывает API из скрипта, получает webp.

## 5. Functional Requirements

- **FR-001** — система должна принимать файл через multipart upload.
- **FR-002** — система должна валидировать пару форматов.
- **FR-003** — система должна обрабатывать конвертацию асинхронно.
- **FR-004** — система должна хранить историю задач пользователя.
- **FR-005** — система должна позволять удалять задачи и файлы.
- **FR-006** — система должна ограничивать размер файла 50 МБ.
- **FR-007** — система должна аутентифицировать по JWT.

## 6. Non-Functional Requirements

- **Производительность:** p95 latency API ≤ 1.2 c.
- **Надёжность:** uptime ≥ 99.5%.
- **Безопасность:** bcrypt для паролей, JWT, rate limit 60 req/min.
- **Масштабируемость:** горизонтальное масштабирование воркеров.
- **Удобство:** Swagger UI на /docs.

## 7. Success Metrics

- DAU: 200 к концу 3-го месяца.
- Retention (7-day): 25%.
- Конверсия в повторную конвертацию: 40%.
- p95 latency: ≤ 1.2 c.

## 8. Release Plan

- **v0.1.0 (MVP):** png/jpg/webp, docx→pdf, регистрация, скачивание.
- **v0.2.0:** csv↔xlsx, API-ключи, rate limit.
- **v1.0.0:** вебхуки, S3-хранилище, мультизагрузка.
